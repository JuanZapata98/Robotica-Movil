# Robotica Movil Controlador con Carla

En este repositorio se encuentran los archivos del controlador y los waypoints para recorrer el RaceTrack en Carla 0.8

Para ejecutar este programa es necesario tener instalado Carla 0.8 y guardar ambos archivos estén en la misma carpeta, que seria la de PythonClient en donde esté instalado Carla

Ejecute en el entorno virtual el siguiente codigo

```bash
python carro_stanley_con_cronometro.py 
```

y el programa se ejecutará una ventana de Carla en la cual se abrirá el mapa de RaceTrack y el carro andará solo, mostrando en consola la posicion en x,y, la velocidad y el tiempo respecto a la linea de meta.

Para finalizar el programa es necesario presionar ctrl + c en la consola y cerrar la ventana de carla.
